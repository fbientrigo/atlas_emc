# Resumen (3–5 bullets)
- Se describe el circuito B13, el cual es un sistema de redundancia que toma una referencia y hacer hecks para así evaluar el estado de salud de los subcircuitos. 
- Se diferencia entre B13 y B13TMR

# Puntos clave (3)
- Permite usar redundancia para evaluar una FPGA bajo un entorno de radiacion
- Existe un pequeño sesgo que es cuando el 2 de 3 circuitos fallan, pero se aproxima a nula esa contribución
