## Physical Reading and FE tests
### Physical Loopback
Using a cable that closes on itself, we get data out from the downlink TX into the RX in order to be read on the uplink then in the registers on the PS (as the AirhHDL module for reading)


Testing sending 0xB8 : 101100
We read:

0x05: 0101
0xC0: 1100

Seeing in binary we can interpret the fact that as our downlink its all zero then each 300ms we send our data 0xB8:
... 0000 0000 1011 1000 0000 0000 ... (original frame bits)
    0     0       B       8      0       0

Then what we read
... 0000 0101 1100 0000 0000 ...( what we read)
    0     5       C      0        0

For this we use the internal signal and we start counting clocks, this allows us to see different clock reads,
as the cable adds some offset from the "send signal" then when we read:
