# Creating epos root filesystem for EMP
-----------------------------------------------------------------------------
This guide explains how to create epos root filesystem for EMP.

Special thanks to our ATLAS colleagues for the [original version of documentation for CentOS](https://twiki.cern.ch/twiki/bin/view/SystemOnChip/CentOSForZynqMP) and to https://gitlab.cern.ch/hardware/zynq/centos8-rootfs authors for the CentOS8 version of the script and methodology.

### **1. Installing epos-fs**
-----------------------------------------------------------------------------
**Step 1.1:** First, binfmt_misc needs to be informed to use static QEMU. Open the following file with your favorite text editor:
```
  $ sudo nano -w /etc/binfmt.d/qemu-aarch64.conf
```
Add the following line to the file:
```
:qemu-aarch64:M::\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\xb7\x00:\xff\xff\xff\xff\xff\xff\xff\x00\xff\xff\xff\xff\xff\xff\xff\xff\xfe\xff\xff\xff:/usr/local/bin/qemu-aarch64-static:
```

**Step 1.2:** binfmt_misc will need to be restarted for the changes to take effect. Use the following command:
```
  $ sudo systemctl restart systemd-binfmt.service
```

**Step 1.3:** Finally, the epos-filesystem can be installed using the following command (extra RPMs can be installed by stating them in `epos_rpms.txt`. Remove this argument if not used):
```
  $ sudo python3 mkrootfs.py --root=$ROOTFS_PATH --extra=epos_rpms.txt
```
The epos filesystem is now created in `$ROOTFS_PATH`. You can copy the root filesystem to your root partition in your SD-card or on NFS directory.

### **2. Adding PetaLinux kernel modules**
-----------------------------------------------------------------------------
PetaLinux comes with its own root filesystem. This filesystem gets built when building PetaLinux using `petalinux-build`. It can be found in `<project-name>/images/linux/`. After building it is in a compressed format. The kernel modules are located inside this filesystem, but not in epos-fs yet. Therefore they need to be copied over.

**Step 2.1:**  Uncompress the `rootfs.tar.gz` file generated by PetaLinux build:
```
  $ cd images/linux/
  $ tar -xvf rootfs.tar.gz
```

**Step 2.2:** In the uncompressed root filesystem got to the `modules` directory in `lib` and copy the folder that is in there to the same location in epos-fs (in this example the name of the folder is **5.4.0-xilinx-v2020.1**. The name depends on the kernel and PetaLinux version):
```
  $ cd /lib/modules/
  $ cp -R 5.4.0-xilinx-v2020.1 /<location-of-epos-fs>/lib/modules/
```
The kernel modules are now added to the epos-fs. Copy the filesystem to the second partition of your SD-card (if you are booting from an SD-card).
